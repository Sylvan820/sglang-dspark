# DMTP

A bilingual research note by Yuhao Shen on combining a pretrained MTP first-token prior with parallel DFlash drafting.

Open `index.html` to read the note. This repository contains the static page, downloadable Markdown, figures, and locally bundled KaTeX fonts and styles.

The previous SGLang content is preserved on `backup/sglang-before-dmtp-20261030` and in Git history.

To publish with GitHub Pages, select **Settings > Pages > Deploy from a branch > main > / (root)**.
